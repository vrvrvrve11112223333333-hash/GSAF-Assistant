# GSAF Assistant

Компактный помощник для **Graveyard Shift at Freddy's 1.0.0** под Windows.

Помощник читает состояние запущенной игры и показывает приоритет действий для Бонни, Чики, Крим, Берри, Слизерс и Фредди. Он не изменяет память игры и сохранения.

## Скачать

Готовые сборки находятся на странице **Releases**. Актуальная версия — **5.4.0**. Старые версии 4.0.0–5.3.1 сохранены в отдельных релизах.

Перед запуском можно сверить SHA-256 с файлом [`SHA256SUMS.txt`](SHA256SUMS.txt). Сборки локальные и не имеют цифровой подписи.

## Основные возможности 5.4.0

- Компактная таблица всех шести противников и шкала угрозы 0–100.
- Строка «СНАЧАЛА» и последовательность действий 1 → 2 → 3.
- Одновременные атаки объединяются в единый порядок приоритетов.
- Точное чтение состояния Фредди, Бонни и музыкальной шкатулки Берри.
- Для Берри отдельно отслеживаются кнопка PLAY/STOP, таймер музыки и текущая фаза.
- Предупреждение о шкатулке за 15 секунд и критическая команда за 6 секунд.
- Спокойные звуковые уведомления и сворачиваемая дополнительная панель.

## Запуск

1. Установите оригинальную игру отдельно. Игра в этом репозитории не распространяется.
2. Поместите `GSAF-Assistant-v5.4.0.exe` рядом с `gsaf-v-1-0-0.exe` и запустите помощник.
3. Если игра находится в другой папке, задайте переменную `GSAF_GAME_PATH` с полным путём к её EXE.

Поддерживается только оригинальный исполняемый файл версии 1.0.0 с SHA-256:

```text
D0C45CAB60567765AE30E5DA70EE58F48234D8107809464A6BF2B4DC6BC795F5
```

## Горячие клавиши

- `Ctrl+Alt+H` — скрыть или показать окна помощника.
- `Ctrl+Alt+R` — переподключить точное чтение состояния.

## Сборка из исходников

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
pyinstaller "GSAF Assistant.spec"
```

Исходник рассчитан на Windows и использует Win32 API для чтения состояния окна и процесса игры.

## Важно

Это неофициальный фанатский инструмент. Он не связан с разработчиком игры или владельцами Five Nights at Freddy's. Репозиторий не содержит оригинальную игру.

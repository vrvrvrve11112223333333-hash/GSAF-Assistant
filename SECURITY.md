# Безопасность

- Помощник открывает процесс игры только с правами чтения.
- Он не записывает данные в память игры и не изменяет сохранения.
- Перед автоматическим запуском проверяется SHA-256 оригинального EXE игры.
- Опубликованные EXE являются локальными неподписанными PyInstaller-сборками.
- Контрольные суммы всех релизов находятся в `SHA256SUMS.txt`.

Не запускайте файл, если его контрольная сумма не совпадает с опубликованной.
